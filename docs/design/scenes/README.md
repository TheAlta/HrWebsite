# تصویرهای نقاشی‌شده سایت

تصویرهای پس‌زمینه سایت (بخش اول خانه، پنجره‌ها، میز کار و تصویر کنار پنل) از نقاشی‌های SVG دموی مالک محصول (`docs/design/demo.html`) ساخته شده‌اند (REPORT #055).

خروجی در `static/img/scenes/` است، هر تصویر در دو حالت روشن و تیره و دو اندازه، با قالب AVIF و WebP.

اگر دمو عوض شد، این دو فرمان تصویرها را از نو می‌سازند:

```
docker compose exec web python docs/design/scenes/render.py
docker compose exec web python docs/design/scenes/convert.py
```

`render.py` نقاشی‌ها را با Playwright به PNG در پوشه موقت کانتینر تبدیل می‌کند و آن‌ها را برای راست‌به‌چپ قرینه می‌کند. `convert.py` از آن PNGها فایل‌های نهایی را می‌سازد.

هر تصویر از پنل مدیریت هم قابل جایگزینی است: بخش اول خانه، بخش «درباره من» و رویدادها فیلد تصویر دارند و اگر خالی بمانند همین نقاشی‌ها نمایش داده می‌شوند.
